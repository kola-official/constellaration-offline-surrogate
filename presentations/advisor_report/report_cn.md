# AI 驱动的仿星器位形优化：从离线代理模型到可信边界诊断

**技术报告**

**作者：Shengnian Liu**

**核心结论**：在所用 68,191 条无错误 Nfp=3 离线训练子集中没有样本同时满足 Problem 2 全部严格约束的设定下，本项目完成了一条从代理模型训练、候选生成到固定预算 VMEC++ 审计的闭环流程。四阶段实验量化了两个关键边界：一是代理模型的**可信范围**，即候选离已有数据多远后预测开始系统性失真；二是当前数据集与搜索预算下的**约束违反下限**，即多种策略都难以继续压低的违反量水平。

主线结果表明，在不引入新物理数据的前提下，离线代理优化主要落入两类行为模式：优化器利用代理模型的乐观误差获得虚高代理分数，或在信任域约束下退回已有数据附近。即便将代理预筛嵌入更接近论文基线的 ALM-NGOpt 搜索逻辑，真实审计结果仍落在随机送审对照分布内部，未跨过官方可行线。由此看，本项目的主要产出是对“MLP ensemble 代理模型 + 无可行侧数据”路线失效机制的定量诊断。

模型路线按四个层级递进：**6 指标主线模型**先完成 E0-E3、Stage 2、Stage 3 与 Stage 4A，建立代理可信范围、违反量下限和随机对照结论；随后才进入三组增量方案。**方案 A（15 指标多任务训练）**同时预测 default 数据中 15 个可用物理指标，输入仍为 80 维 Fourier 边界系数，评分仍只读取 Problem 2 的 6 个主指标。该方案改善了 `log10_qi` 表示和候选 VMEC++ 可计算性，并将 Stage 4 的最好真实违反量推进到 0.29535；但所有审计组仍为 0 个官方可行解，且随机对照也进入相近区间。方案 A 提升了监督预测与候选可计算性。可行性仍待突破。

**方案 B-small（wout 中间监督）**从 VMEC++ 的 wout 平衡输出中提取 24 个低维中间物理标签，仅作为训练阶段的辅助监督；推理仍只输入 80 维边界系数，候选评分仍只读取 Problem 2 的 6 个主指标和连续违反量。wout24 多头模型可正常训练，测试集 wout 辅助头平均 R² 约 0.857，`log10_qi` 测试 MAE 降至 0.03817；但在同样每方法 top10 的 VMEC++ 审计下，最好真实违反量仍为 0.322441，与 15 指标模型持平，且 E3 成功率从 10/10 降至 3/10。该结果说明中间监督结构可行。当前候选 scoring 尚未把它转化为审计收益。

**方案 C（cross-Nfp 预训练 -> Nfp=3 微调）**在 15 指标默认训练协议基础上完成三种子消融，并将 gate 选出的低学习率微调模型接入 E0-E3、Stage 2、Stage 3 与 Stage 4A 完整下游审计。监督层面，预训练初始化稳定降低 `log10_qi` MAE 和连续违反量 MAE：优化验证集 `log10_qi` MAE 从 0.04326 降至 0.03446-0.03492，测试集从 0.03927 降至约 0.0320-0.0322；optimistic gap 未稳定改善。真实审计层面，cross-Nfp downstream 仍为 0 个官方可行解；Stage 4A 最好正向最大违反量为 0.31186，略优于 Stage 1-3 历史最好 0.32244，但随机对照 30 次重复的中位数为 0.31657、5-95% 区间为 0.31135-0.32463，S4A-4 只位于随机分布约 0.0667 分位，未越过 5% 显著尾部。这表明跨 Nfp 数据适合作为表征初始化来源；可行性偏差和候选审计问题仍然存在。

## 第一部分：背景与问题难点

### 1.1 仿星器与设计瓶颈

聚变能是未来能源体系的重要候选方向。在磁约束聚变路线中，仿星器（stellarator）依靠**外部扭曲线圈**产生三维约束磁场，不像托卡马克那样依赖较大的等离子体内部电流，因此在原理上可避免电流驱动的破裂不稳定性，并具有稳态运行潜力。这一优势伴随更高的设计复杂度：仿星器磁场位形优化是一个高维、强约束且单次评估昂贵的问题。

仿星器设计通常分为两个阶段：第一阶段优化约束磁场对应的**最外层等离子体边界磁面形状**，第二阶段设计能够复现该磁场的线圈。本项目聚焦第一阶段。该边界磁面在数学上用截断傅里叶级数参数化（柱坐标下的 R、Z 系数）；给定一组边界系数后，需要调用理想磁流体（ideal-MHD）平衡求解器 **VMEC++** 计算内部磁场，并从平衡解中导出准等动力学相关指标、环径比等物理量。

关键难点在于：**VMEC++ 是昂贵的物理仿真**。ConStellaration 论文报告，基于 VMEC++ 的第一阶段优化在 32 vCPU 机器上平均约需一小时；本地对固定候选进行单次 VMEC++ 求解时，成功求解一个候选约需 119-125 秒。二者计时口径不同，但均表明 VMEC++ 不适合直接嵌入大规模搜索内循环。这也是使用代理模型加速甚至部分替代物理内循环的主要动机。

### 1.2 ConStellaration Benchmark 与 Problem 2

本项目基于 Proxima Fusion 开源的 ConStellaration benchmark。该工作发布了约 15.8 万条无错误的 QI-like 仿星器边界样本及其 VMEC++ 平衡解与物理指标，并定义了三个递进的优化问题。本项目选择其中的 **Problem 2：simple-to-build QI stellarator（易于制造的准等动力学仿星器）**。

准等动力学（quasi-isodynamic, QI）是一类通过使被俘获粒子的平均径向漂移接近零来抑制粒子损失的磁场性质，被认为是通向商用聚变电站的潜在路线之一（W7-X 即近似 QI）。“易于制造”指所需磁场可由相对简单的线圈产生，该性质用边界上的**归一化磁场梯度尺度长度 L_∇B** 量化：L_∇B 越大，线圈可离等离子体更远、弯曲更平缓，制造难度相对更低。

Problem 2 可表述为一个 **80 维带约束黑盒优化问题**：

- **设计变量**：stellarator 对称的 SurfaceRZFourier，最大极向/环向模数均为 4，场周期数 Nfp=3，有效自由度约 80 维。
- **目标**：最大化 L_∇B（线圈可制造性指标）。
- **约束**：环径比 A ≤ 10；边界旋转变换 |ι/Nfp| ≥ 0.25；QI 残差 log₁₀(qi) ≤ -4.0；边界磁镜比 ≤ 0.2；最大拉长比 ≤ 5.0。
- **可行判据**：所有归一化约束违反量均 ≤ 1×10⁻²。
- **官方评分**：可行时 score = L_∇B / 20；只要任一约束不满足，score 即为 0。

这条评分规则是该问题的关键特征：Problem 2 采用全部约束同时满足的硬门槛评分规则。任一约束不达标，候选的官方得分即归零。这决定了后续分析必须将“可行性”置于“目标值”之前。

## 第二部分：问题抽象与技术路线选型

### 2.1 问题抽象

面对这一问题，本项目采取的策略是先确立“背景-目标-约束”，再将系统拆分为可独立验证、可按优先级推进的模块。Problem 2 可归结为典型的**高维、强约束、昂贵黑盒优化**问题，其三个特殊性质直接决定了后续方案选择：

1. **评估昂贵**：目标和约束真值均需通过 VMEC++ 获得，直接在物理仿真中进行大规模全局搜索不现实。
2. **约束主导**：官方评分为硬门槛，绑定约束（后文可见主要为 log₁₀(qi)）决定成败；目标值只有在可行后才有意义。
3. **数据有偏**：官方数据库虽大，但在所用的 Nfp=3 无错误子集中，满足 Problem 2 官方可行标准的样本数为 0。论文报告，在约 16 万样本上，Problem 2 只有在放宽约束后才找到 52 个近可行点。这说明可行域在当前数据中高度稀疏，甚至可能未被覆盖。

第三点是整个项目的核心风险，并在项目开始时即被列为最高优先级。

### 2.2 候选技术路线的调研与取舍

问题设定允许自由选择路线，包括梯度局部优化、贝叶斯优化、遗传/进化等全局算法、强化学习、生成模型和大模型 agent 等。本项目依据“评估昂贵 + 约束主导 + 无可行样本 + 有限 GPU 算力预算”这组条件筛选路线：

- **局部优化方法**：ConStellaration 论文中的 scipy-trust-constr 与 COBYQA 均属于局部优化范畴，其中 trust-constr 通常需要梯度或有限差分近似，COBYQA 是无导数约束局部优化。此类方法在高维约束空间中仍需反复调用 VMEC++，且论文中这两个方法在 Problem 2 上均未得到可行解；在本项目的算力预算下不适合作为主线。
- **进化 / 增广拉格朗日直接物理优化**：论文中的 ALM-NGOpt 是其报告中在 Problem 2 上取得可行解的参考基线，但其在 96 vCPU 上运行约 34 小时，无法在同等预算下复现。因此，本项目仅将其作为外部参考。
- **贝叶斯优化**：适合单次评估昂贵的问题，但在 80 维空间中高斯过程的扩展性和采样效率受限，且仍需在线调用 VMEC++ 获取新观测。
- **强化学习**：通常样本效率较低，需要大量环境交互；在本问题中，环境交互等价于大量 VMEC++ 调用，与减少物理调用的目标不一致。
- **生成模型 / 离线代理模型**：利用已有的 15.8 万样本数据库离线训练廉价预测模型，使优化器主要查询代理，并在最终阶段用 VMEC++ 审计候选。该路线可训练、可审计、可快速迭代，并充分利用 benchmark 最大的数据资产，同时契合现有工程背景与 GPU 条件。

**据此，本项目选定离线代理模型辅助优化（offline surrogate-assisted optimization）为主线。** 这一选择也有论文依据：ConStellaration 论文第 5 节展示了基于数据训练的模型可在不频繁调用昂贵物理仿真的情况下生成候选配置，说明数据驱动路线在该 benchmark 上具有探索价值。项目贡献边界也随之明确：**本项目聚焦代理模型与搜索这一层**。磁面物理表征不在本项目范围内。

### 2.3 代理模型的选型

确定主线后，代理模型本身仍需针对问题特性设计。设计目标是：既能预测目标值，又能预测各约束违反量，并能提供不确定性估计，以支撑后续保守搜索。最终采用**谱感知的多任务深度集成 MLP（Spectral Multi-task Deep Ensemble MLP）**：

- **多任务学习**：一个网络同时回归 6 个物理指标（L_∇B、环径比、|ι/Nfp|、log₁₀(qi)、磁镜比、最大拉长比），共享中间表征。
- **连续约束违反量回归头**：这是一个关键设计。由于训练数据中官方可行样本为 0，若直接训练“可行/不可行”二分类器，标签将几乎全为负类，模型无法学习有效的可行边界。因此改为使用 Huber 损失回归连续的 `max_normalized_violation`，候选生成阶段再依据官方阈值将连续违反量转化为可行性惩罚，从而绕开全负类标签的问题。
- **深度集成**：使用 4 个不同随机种子的成员模型，集成成员间分歧提供不确定性估计，用于对模型把握不足的区域施加惩罚。
- **谱感知预处理**：按确定的 (m,n) 顺序展平傅里叶系数，使用训练集统计量标准化，并保留模式索引信息，使高阶模式在候选生成时可被单独约束。该处理保留模式索引信息，并增强代理模型对边界谱结构的敏感性。
- **超参数**：宽度 256、3 个残差块、SiLU 激活、dropout 0.03、AdamW、学习率 1e-3、batch 2048，双 GPU 并行训练。

训练时使用 4 个 ensemble 成员，随机种子分别为 0、1009、2018 和 3027，并在两张 GPU 上交错训练。每个成员最多训练 80 个 epoch，early stopping patience 为 12；实际最优 epoch 分布在 71-78。输入特征使用训练集统计量标准化，6 个物理回归标签也按训练集均值和标准差做 Z-score。候选生成阶段保留 ensemble 均值作为物理量预测，保留成员间标准差作为不确定性；`max_normalized_violation` 的温度参数设为 0.05，用于把连续违反量映射为近似不可行概率，但不把它当作真实二分类标签。

该选型与论文附录 A.4 的观察一致：论文同样采用 MLP 集成验证数据的可学习性，并定性指出代理模型在远离训练分布时容易出现外推误差。后续四阶段实验正是围绕这一预警展开：本项目不只验证代理能否拟合已有数据，还检验它在优化压力下何时失效，并把外推风险从定性提示推进为可测量的定量边界（第四、五部分）。这也是本项目相对论文的一个具体着力点：论文点出了风险的存在，本项目量化了风险的形状。

### 2.4 搜索与诊断技术说明

本项目用到的优化器都属于无导数连续优化方法，原因在于真实目标和约束来自 VMEC++ 或代理模型，可用的可靠物理梯度通常不可得。**CMA-ES**（Covariance Matrix Adaptation Evolution Strategy）可理解为“带协方差学习的进化搜索”：优化器在当前均值附近从多元高斯分布采样候选，再根据候选得分更新均值、步长和协方差矩阵，使后续采样更集中到高分方向。它适合连续、非凸、梯度不可得的问题，也常被用于高维黑盒优化。本项目调用 Nevergrad 中的 `CMA` 实现，通过 `ask/tell` 接口把候选傅里叶系数送入代理模型打分；由于 Nevergrad 默认是最小化接口，代码中实际传入的是负的代理得分。

**NGOpt** 是 Nevergrad 提供的组合型黑盒优化器，会根据变量类型和预算选择较稳健的内部策略。它采用工程化 optimizer portfolio，根据变量类型和预算选择内部策略。本项目在 Stage 1 的纯代理搜索、Stage 2 的部分潜空间搜索以及 Stage 4 的代理 ALM 搜索中使用 NGOpt，是为了在固定计算预算下减少为每类搜索空间单独调优化器的成本。**ALM-NGOpt** 则是在 NGOpt 外面包一层增广拉格朗日（Augmented Lagrangian Method, ALM）：把“最大化目标且满足约束”的问题转成带惩罚项的无约束目标，约束违反越大惩罚越大，并按固定间隔更新拉格朗日乘子。本项目 Stage 4 保留的是这种“ALM 约束处理 + NGOpt 提议候选”的思想，但评价器替换为代理模型，所以它是离线代理预筛实验，与论文中把 VMEC++ 放进优化内循环的在线 ALM-NGOpt 采用不同评价流程。

**PCA** 与 **GMM** 的作用是给搜索空间增加数据几何先验。PCA 将 80 维傅里叶系数投影到由真实样本拟合出的低维线性子空间，避免逐维独立采样破坏边界系数之间的相关结构；GMM 在 relaxed55 的 PCA 坐标中拟合若干个高斯分量，用来生成靠近近可行种子的局部候选。本项目的**信任域**由 ensemble 不确定性、训练集最近邻距离、relaxed55 最近邻距离和谱合法性共同定义。后文所说的 **surrogate arbitrage**，指优化器利用代理在训练边界处的系统性乐观误差获得虚高代理分数；第二、三阶段的设计正是为了识别这种行为。

## 第三部分：整体方案与实验边界

### 3.1 离线优化闭环

整条流程遵守一条硬规则：**VMEC++ 只用于固定预算终审，不进入训练、模型选择、搜索内循环或权重调参，审计结果也不回流到模型。** 这保证了方法是真正的离线流程，不会隐式利用昂贵的物理仿真。

大规模离线数据库 -> 训练代理模型 -> 多组策略生成候选 -> 固定预算 VMEC++ 审计 -> 诊断分析。

固定预算的含义是：每个主方法只取排序前 10 个候选进入 VMEC++ attempted slots，几何非法或求解失败同样计入分母，不用“只统计成功求解”的方式美化效率。候选生成阶段则远大于审计预算：第一阶段每组保留 200 个候选，E2/E3 的代理搜索预算为 3000 次；第二阶段同样每组保留 200 个候选；第三阶段只审计 8 个信任域候选；第四阶段每个主方法审计 10 个候选，并额外使用随机辅助审计来估计随机送审的真值分布。这个设计把“廉价生成”和“昂贵确认”明确分开，保证结论只来自真实物理审计。

其中 55 个放宽标准样本（下称 relaxed55）承担一个特定角色：它们**不进入训练/验证/测试集**，仅作为局部生成的**种子先验**，即提示优化器“这些位置虽未达到官方可行标准，但比普通样本更接近目标，应优先在附近搜索”。需要强调的是，relaxed55 不是官方可行集，只是根据论文处理方法在当前数据上放宽标准后的近可行种子。

### 3.2 数据与算力边界

- 本地使用 HF 数据库中约 18.2 万条训练样本，其中无错误样本 15.8 万条，无错误且 Nfp=3 的子集为 **68,191 条**。
- 官方 Problem 2 可行样本：**0 条**。
- relaxed55：依据论文放宽标准方案（放宽因子 0.33）在本地筛得的 **55 个**近可行种子。该数字与论文报告的 52 个不完全一致，可能源于本地筛选口径与数据库版本差异。
- 代理模型训练划分：训练集 47,694；验证集 10,221；测试集 10,221；另有从验证集派生、绝不用于训练的优化验证集 3,589。
- 硬件：实验在配备两张消费级 GPU 的服务器上完成。GPU 主要用于代理模型训练；本次代理推理基准默认将 4 个集成成员加载到第一块 GPU，VMEC++ 审计则主要受 CPU 与求解器设置影响。该硬件配置与论文基线的 96 vCPU x 34 h 不在同一量级，因此论文基线仅作为外部参考。

relaxed55 的筛选阈值也需单独说明。官方阈值为 A ≤ 10、|ι/Nfp| ≥ 0.25、log₁₀(qi) ≤ -4.0、mirror ≤ 0.2、elongation ≤ 5.0；放宽筛选将其中几个约束放宽为 |ι/Nfp| ≥ 0.1675、log₁₀(qi) ≤ -2.68、mirror ≤ 0.266、elongation ≤ 6.65，环径比仍保持 A ≤ 10。也就是说，relaxed55 是“比普通样本更接近官方目标”的局部先验，仍未达到官方可行标准。所有训练、验证、测试切分均排除 relaxed55，避免把种子先验泄漏进模型训练。

需要澄清一处方法学要点，即本项目使用的**输入特征**与**监督标签**的性质，这直接关系到代理模型的可靠性：

- **输入特征**：始终是边界的傅里叶系数（约 80 维），不使用 VMEC++ 的 wout 平衡输出作为输入。这是刻意的设计：若把 wout 当输入，则每评估一个候选都要先跑一次 VMEC++，代理模型也就失去了加速意义。
- **高保真物理标签**：6 个基础物理指标（L_∇B、log₁₀(qi)、edge iota、mirror、elongation、aspect ratio）本身是 default 数据集中由 Proxima 用 VMEC++ 高保真前向模型算出的量，属于可靠的物理监督标签。
- **规则派生的弱标签**：`max_normalized_violation`、relaxed feasible、score 等，是在上述物理指标之上、按官方阈值规则再加工出来的。本项目代理只回归高保真物理量，再由规则将其换算为可行性惩罚，因此不直接依赖这些弱标签作为回归目标。

当前训练标签的主体是可靠的物理量。后续改进将补充覆盖官方可行侧的**新的**高保真评估（见第七部分）。

### 3.3 单次评估的耗时对比

离线代理路线的核心动机，是用廉价代理查询替代昂贵物理求解。该动机可通过单次评估耗时的数量级差异定量说明。

**VMEC++ 侧（专门基准实测）**：本地基准为 4 进程并行的固定候选审计。论文中的完整在线优化是另一套流程。4 个代表候选中有 3 个成功求解，耗时分别为 118.7、125.0、125.5 秒；成功求解的均值约 123 秒，中位数约 125 秒。另有 1 个几何非法候选在 0.041 秒即失败退出。该失败记录不计入成功求解均值：它无法代表一次有效物理求解的成本。论文报告的“32 vCPU 上约一小时”对应基于 VMEC++ 的完整第一阶段优化；本地数字对应固定候选的单次求解。两套口径只作量级参照。

**代理侧（3000 次评估实测）**：在服务器上以 3000 次代理评估为预算，分三种调用方式测量。按批量整体前向计算时，3000 个候选总耗时约 0.0049 秒，合 0.0016 毫秒/次，显存占用约 25 MiB；该值仅代表模型吞吐上限，不等同于真实优化循环。按单样本逐次调用时，3000 次总耗时约 9.43 秒，合 3.14 毫秒/次。最接近实际 CMA-ES 搜索的逐步评估方式下，E2 完成 3000 次评估需 29.0 秒（9.67 毫秒/次），E3 需 19.6 秒（6.53 毫秒/次）。该基准使用单张 GPU 推理，进程常驻内存约 1.43 GiB，显存占用约 273 MiB。

**量级对比与边界**：若以成功物理求解均值约 123 秒估算，3000 次真实 VMEC++ 评估约需 10.3 万秒（约 102.6 小时）。与逐步代理评估的 19.6-29.0 秒相比，代理搜索的评估环节约快 1.3 万至 1.9 万倍。这一数量级差异支持了代理路线的加速动机。但加速价值必须与代理可信范围同时评估：第四、五部分将表明，一旦搜索离开代理可信区域，低成本查询会给出系统性偏乐观的预测；评估越快，优化器也越快被引向错误区域。

## 第四部分：四阶段实验

四阶段实验按递进问题展开：先验证代理在数据分布内的学习能力，再检查搜索生成的几何能否被 VMEC++ 求解，随后区分真实瓶颈来自几何、代理偏差还是数据覆盖，并检验代理预筛嵌入 ALM-NGOpt 搜索逻辑后，相对随机送审是否具有可归因的增量。

### 4.1 第一阶段：代理在数据分布内有效，但直接优化失败

**训练结论**：测试集上 L_∇B 的 R² 约 0.927，最大约束违反量的 R² 约 0.982，log₁₀(qi) 的 R² 约 0.965。在已有数据分布**内部**，模型能够较准确地预测目标与约束。由于没有任何官方可行正例，模型所学到的“可行性”只能来自连续违反量的插值和外推，训练支持中没有真正的可行域样本。

**四组候选生成策略**：

- **E0（数据库基线）**：直接从 68k 数据库中筛选最接近可行的样本，排序规则是先比较约束违反量、再比较目标值。该组不使用任何模型，也不做搜索，仅作为“完全不优化”的对照，用于标定数据库本身能达到的水平。10/10 通过 VMEC++ 求解，0 个官方可行，最好目标值约 9.65。
- **E1（relaxed55 附近局部生成）**：对 relaxed55 的傅里叶系数做 PCA 降维，在低维空间用高斯混合模型（GMM）拟合局部分布并采样，解码回系数后用本项目训练的代理模型打分排序，保留排名靠前的候选。它使用了本项目的代理模型，属于“围绕近可行种子的局部生成”。10/10 通过求解，0 个官方可行，最好目标值约 8.45。该策略稳定，但未跨过可行线。
- **E2（纯代理搜索）**：只信任代理模型的预测，在原始 80 维系数空间中用 CMA-ES 直接搜索代理分数最优的点。10 个候选全部 VMEC++ 失败。
- **E3（保守搜索）**：从 relaxed55 种子出发，同样用 CMA-ES 搜索，但在代理分数上附加不确定性、数据距离、约束违反等保守惩罚，以抑制搜索离开数据支撑区域。仅 1/10 通过 VMEC++ 求解。

该阶段的关键参数如下：E1 将 relaxed55 压缩到 10 维 PCA 空间，使用 4 个 GMM 分量采样 2000 个局部候选，再由代理模型排序并保留 200 个候选池；E2/E3 每组进行 3000 次代理查询，保留 200 个候选池，最终各取前 10 个进入 VMEC++ 审计。E2 的代理分数主要奖励高 L_∇B，因此容易追到代理认为目标值很高、但几何结构已经脱离真实边界流形的区域；E3 在 E2 的基础上加入 ensemble 不确定性、训练/验证支撑距离和约束违反惩罚，试图把候选压回 relaxed55 附近。实际审计显示，E3 只保住了初始化附近的少量可运行候选，CMA-ES 后续漂移候选仍大量失败。

E0-E3 与论文方法的关系如下：E0 为纯数据筛选；E2、E3 为本项目设计的代理搜索策略。E1 借鉴论文第 5 节在放宽问题上使用 PCA 与 GMM 刻画近可行分布的思路，并采用 GMM 采样与代理打分生成、排序候选。论文方法采用随机森林分类器与 MCMC 后验采样。两者的目标、组件和采样流程不同，E1 属于结合本项目代理模型实现的分布建模变体。

关于为何未与论文数据方法做数值正面对比，需要区分论文中两个不同口径：论文第 5 节的数据驱动生成方法只在**放宽版**问题上做了演示，报告的是分类器与物理仿真均判为可行的样本区域，并未给出 Problem 2 的官方得分；全文唯一带 Problem 2 官方得分的方法是第 4 节的 ALM-NGOpt（0.431）。因此不存在一个与 0.431 可比的数据方法得分可供列表对照。本项目在方法思路层面与 E1 对齐。论文的数据驱动方法同样停留在放宽问题上、未跨过 Problem 2 的官方可行线，与本项目“固定代理加无可行侧数据难以跨线”的观察一致。

第一阶段分清了两类失败模式。E2 候选在进入物理指标判定前即因几何非法而求解失败。在逐维盒约束的边角处，各系数单独位于允许范围内，组合后可能无法构成合法、平滑的边界曲面。对于能够通过求解的候选，主导失败约束几乎均为 log₁₀(qi)。**第一阶段结论：搜索空间设置不当会直接产生大量几何非法候选。**

### 4.2 第二阶段：修正几何后，优化器转而利用代理预测误差

针对第一阶段的几何非法问题，第二阶段做了三处修正，且不覆盖第一阶段结果：

1. **更换搜索空间**：将 CMA-ES 从原始系数空间迁入用真实边界数据拟合的 **PCA 潜空间**（E2 用训练集拟合，E3 用 relaxed55 拟合），使采样自然落在真实边界流形附近，显著提高几何合法性。
2. **可行性优先目标**：将目标函数从“先追高 L_∇B”改为分优先级优化，即先重罚约束违反，尤其是 log₁₀(qi) 违反；接近可行后再提高目标值。
3. **谱预筛 + 去重**：送入 VMEC++ 前，先用廉价的谱合法性检查剔除非法几何，并按边界哈希与潜空间距离去重，避免将审计预算耗费在近重复候选上。

第二阶段的具体设计比第一阶段更保守。E2-stage2 使用训练集拟合 20 维 PCA 潜空间，解释方差约 0.995；E3-stage2 使用 relaxed55 拟合 10 维 PCA 潜空间，解释方差约 0.991。潜空间每一维的边界取训练投影坐标的 0.5% 与 99.5% 分位，解码回 80 维后再裁剪到训练集系数范围内。谱过滤器使用训练集高频能量比例和最大系数的 99.5% 分位乘以 1.25 作为阈值，实际阈值约为高频能量比例 0.00593、最大系数 0.634。排序时使用可行性优先分数：L_∇B 的权重为 0.25，正向最大违反量权重为 80，log₁₀(qi) 违反权重为 40，不可行概率权重为 2；E3-stage2 额外对不确定性和支撑距离各加权 2，对几何惩罚加权 8。只有当预测正向违反量降到 0.05 以内时，目标值才获得额外奖励。

这一阶段最有诊断价值的结果，是一个表面反常但机制清晰的现象：

- E3-stage2 的 VMEC++ 成功率从旧的 1/10 提升至 **6/10**，说明几何问题确实得到缓解。
- 但真实约束 gap **反而变差**：最好正向最大违反量为 0.437（旧最好为 0.32214），最好 log₁₀(qi) gap 为 1.748（旧最好为 1.285）。

将 6 个通过求解的候选逐一对照其**代理预测值与 VMEC++ 实测值**后，机制变得清晰：这些候选的**预测** log₁₀(qi) 全部集中在约 -2.90（接近训练数据最低值），**预测**违反量也集中在 0.29 附近；而 VMEC++ 实测的 gap 却散布在 0.44-0.51。换言之，优化器并未找到真实更优解，而是收敛到了**代理模型系统性过于乐观的区域**，也就是模型预测偏差最大的位置。

这一现象的实质是：约束惩罚权重越高，优化器越倾向于寻找“代理把违反量低估得最多”的位置，以模型预测误差换取虚高代理分数。更深层原因在于，代理对 log₁₀(qi) 的预测在训练数据最低值 -2.9 附近出现**饱和**；模型从未见过更低的值，向外推时只能给出并不可靠的乐观预测。**第二阶段结论：几何修正之后，固定不变的代理仍会被优化器利用。主要瓶颈转向数据覆盖不足。**

### 4.3 第三阶段：以信任域诊断指向数据覆盖不足

第三阶段不再继续调权重，而是转向诊断。项目将所有阶段的候选按“距训练流形的距离”与“预测-实测偏差”对齐，绘制代理有效性曲线；随后进行**信任域消融实验**，即只允许在集成分歧低、离训练数据与 relaxed55 都较近的高置信区域内选取候选，并观察候选来源和真实表现。

信任域的实际参数来自验证集与 relaxed55 的距离分布。训练流形距离使用 20 维 PCA，阈值取验证集最近邻距离的 50% 分位，实际约 0.00226；relaxed55 距离使用 10 维 PCA，阈值取 relaxed55 内部非零最近邻距离的 75% 分位再乘 1.5，实际约 0.04262。候选还需满足 log₁₀(qi) ensemble 标准差不超过 0.06、L_∇B 标准差不超过 0.20、最大违反量标准差不超过 0.04。候选池由已有阶段候选、relaxed55 种子和 1200 个 relaxed55 局部扰动样本共同组成；通过这些筛选后，写出的 125 个候选中，排名前 20 全部来自 E0 数据库基线，最终仅审计前 8 个。

**两个关键结果**：

1. **代理的系统性乐观被定量确认**：第二阶段通过求解的候选，其预测 log₁₀(qi) 中位数约为 -2.906，实测中位数约为 -2.082，即模型平均乐观约 **0.83 个 log 单位**。该偏差随“距训练数据的距离”增大而单调上升：E0（就在数据上）偏差仅为 0.02-0.08，E1（距数据 6-10 倍近邻距离）偏差升至 0.27-0.62，E2（距数据约 19 倍）则全部无法求解。也就是说，离数据越远，代理越乐观；超过一定距离后，候选甚至不再可由 VMEC++ 求解。这条曲线刻画了代理的可信范围。
2. **信任域筛选使候选退回数据库**：一旦要求“只在代理可信区域内搜索”，排名靠前的候选全部退回 E0 来源。8/8 通过 VMEC++ 求解，但未产生新的有效区域。信任域能挑出 qi 分量更优的样本（第三阶段最好 log₁₀(qi) gap 降至 1.064，优于旧的 1.285），但整体最大违反量停在 0.3305，仍未优于 E0 的 0.32214。

**第三阶段结论：主要瓶颈指向缺乏可行侧或足够近可行侧的数据。继续调整搜索权重难以单独解决该问题。**

### 4.4 第四阶段：代理辅助 ALM-NGOpt 与随机预筛对照

第四阶段检验代理预筛嵌入 ALM-NGOpt 搜索逻辑后的效果：代理模型承担大规模候选评价，少量候选进入 VMEC++ 审计。实验在固定审计预算下比较代理预筛与随机送审，评价代理排序能否提供可归因的增量。

Stage 4A 设计了五组候选。S4A-1 是原始系数空间中的纯代理 ALM-NGOpt，主要作为诊断组；S4A-2 和 S4A-3 分别在训练集 PCA 空间与 relaxed55 PCA 空间内运行代理 ALM-NGOpt；S4A-4 从 S4A-2/3 的可信候选中做多样性重排；S4A-R 则在同一候选池中随机抽样送审，用于隔离“ALM-NGOpt 生成候选池”与“代理打分预筛”两部分贡献。主审计预算严格保持为每组 10 个 VMEC++ attempted slots，失败或几何非法候选也计入分母；另额外审计 190 个随机辅助候选，只用于估计 30 次 S4A-R 随机重复的真值分布，不并入主效率分母。

该阶段的代理搜索预算为每组 4 个随机种子，每个种子 1200 次代理查询，合计每组 4800 次；每组候选池上限为 120。S4A-2 的训练集 PCA 维数为 24，S4A-3 的 relaxed55 PCA 维数为 10。ALM 惩罚参数 ρ 设为 20，每 200 步更新一次拉格朗日乘子；代理目标中除 L_∇B 与五个预测约束外，还加入 log₁₀(qi)/L_∇B 不确定性、训练流形距离、relaxed55 距离和谱几何惩罚。候选最终排序综合代理目标值、预测正向违反量、qi 违反量、不确定性、训练流形距离和几何风险。较高的约束权重用于抑制 Stage 2 中已经观察到的“代理高分但真实更差”现象。

结果显示，S4A-1 与 S4A-2 的主审计候选均 10/10 VMEC++ 失败，说明纯代理与过窄训练流形中的 ALM 搜索仍会产生物理求解器不可接受的边界。S4A-3 10/10 通过求解，最好正向最大违反量为 0.31668；S4A-4 9/10 通过求解，最好值为 0.31318；S4A-R 7/10 通过求解，最好值为 0.31547。所有组均为 0 个官方可行解。相对于 Stage 1-3 历史最好值 0.32214，S4A-4 确实有小幅推进；但 30 次随机对照的最好违反量中位数为 0.31589，5-95% 区间为 0.31212-0.33183，最小值为 0.31170。S4A-4 对应的随机分布百分位为 0.20（数值越低越好），即约 20% 的随机抽样可达到或优于 S4A-4。

第四阶段的归因结论是：**ALM-NGOpt 搜索逻辑和更大的候选池可能有助于把违反量略微推向 0.31-0.32 区间，但代理打分预筛相对随机送审没有可证的额外贡献。** 这一结果支持暂缓 Stage 4B 主动学习回填：4B 的前提是 4A 已证明代理预筛真实有效。当前 S4A-4 仍落在随机对照分布内部，小幅改善尚难可靠归因于代理预筛。

## 第五部分：关键证据与随机对照

### 5.1 证据一：代理的可信范围

![代理模型可信范围](../../figures/final-negative-result/fig1_surrogate_validity_boundary.png)

第一张图以候选距训练流形的相对距离为横轴（对数轴），以 log₁₀(qi) 的“实测 - 预测”偏差为纵轴。E0、E1、E2 三簇点连成一条单调上升的曲线，并在约 19 倍距离处达到 VMEC++ 无法求解的阈值。该图将“代理可信范围”从定性判断转化为可测量曲线，是整个负结果的核心证据之一。

### 5.2 证据二：违反量的下限

![正向最大约束违反量下限](../../figures/final-negative-result/fig2_constraint_floor_positive_violation.png)

第二张图将前三阶段各方法的正向最大约束违反量绘成分布，可见在本数据集与本搜索预算下，多种方法都难以压低的一条水平线，约在 **0.32**。E0 为 0.32214，第三阶段为 0.3305。第四阶段的审计表进一步补充了这一判断：S4A-4 的最好值为 0.31318，随机对照 30 次重复的中位数为 0.31589、最小值为 0.31170。换言之，引入 ALM-NGOpt 搜索逻辑后，候选确实更密集地贴近 0.31-0.32 区间，但仍未形成通向官方可行阈值的突破。后续 15 指标复跑进一步将绝对最好值推进到 0.29535，但随机对照也同步进入相近区间，因此不改变“可行性鸿沟仍未跨越”的判断。这一 0.29-0.32 附近的水平线可视为当前数据条件下“可行性鸿沟”的经验厚度：绑定约束 log₁₀(qi) 距官方阈值 -4.0 仍差一个数量级以上（relaxed55 的 log₁₀(qi) 超出量中位数约为 1.26）。

### 5.3 证据三：Stage 4A 随机对照

Stage 4A 通过随机送审对照判断 S4A-4 的改进是否具有可归因性。审计效率定义为 `(best_violation_baseline - best_violation_method) / n_vmec_calls`，其中 `n_vmec_calls` 为主审计 attempted slots，失败调用同样计入分母。S4A-4 相对 Stage 1-3 历史最好值的审计效率为 8.96×10⁻⁴/次，表面上优于历史基线；但随机对照 30 次重复的中位数也已优于 Stage 1-3 历史最好值，说明“更大的 ALM-NGOpt 候选池”本身已有贡献。S4A-4 只达到随机分布的 0.20 分位，未落在 5% 显著尾部之外。改善尚难归因于代理预筛。

为避免“6 指标主线、15 指标方案 A、wout24 方案 B-small、cross-Nfp 方案 C”在叙事中被拆散，第三张综合对比图把四套方案放进同一坐标系：Stage 1 的 E0-E3 审计、Stage 2/3 诊断、Stage 4A 随机对照以及监督 `log10_qi` MAE 分别作为四个面板。该图的读法是：监督指标从 6 指标到 cross-Nfp 持续改善，但 VMEC++ 审计仍全部停在官方可行阈值以上；B-small 未运行的后续阶段被显式标为 not run，图中不补充推测数据点。

### 5.4 补充证据：从 6 指标主线到 15 指标方案 A

在完成 6 指标主线后，本项目按“default 全部物理指标多任务训练”的思路复跑了一版 15 指标代理模型。该方案的边界是：训练阶段让网络同时预测 Problem 2 的 6 个主指标和 9 个辅助物理指标，以迫使共享隐层学习更完整的边界到物理响应映射；线上候选生成时仍只输入 80 维 Fourier 边界系数，不使用 wout；线上评分也仍只读取 Problem 2 的 6 个主指标及其派生违反量。该设置保持了离线推理能力，并避免将 VMEC++ 平衡解泄漏进输入。

模型层面，15 指标训练确实带来小幅但一致的表示改进：测试集 `log10_qi` MAE 从 0.04292 降到 0.03963，优化验证集 `log10_qi` MAE 从 0.04649 降到 0.04348，测试集 `L_∇B` MAE 从 0.27319 降到 0.26417。与此同时，优化验证集 `max_normalized_violation` MAE 从 0.03082 变为 0.03118，说明连续可行性边界本身并未稳定变准。

审计层面，前几阶段最清楚的变化是可计算性提升；正向最大违反量没有同步下降。Stage 1 中，E3 的 VMEC++ 成功率从旧 6 指标模型的 1/10 提升到 10/10，但最好 positive max violation 为 0.38242，仍差于 E0 数据库基线的 0.32244。Stage 2 中，E3-stage2 从 6/10 成功、最好 0.43698，提升到 10/10 成功、最好 0.38242；E2 与 E2-stage2 仍均为 0/10。Stage 3 中，trust-region 候选保持 8/8 成功，最好 positive max violation 仍为 0.33047，但 `log10_qi` gap 中位数从 1.31932 降到 1.22881，说明 QI 方向有一定改善。

Stage 4 的结果最值得单独说明：S4A-4 的最好 positive max violation 从旧 6 指标模型的 0.31318 降到 0.29535，S4A-3 也从 0.31668 降到 0.29984，绝对结果进入 0.29-0.30 区间。但随机对照也同步前移，30 次随机重复的中位最好违反量从 0.31589 降到 0.30236，最小值从 0.31170 降到 0.28841；新 S4A-4 只位于随机对照的约 0.0667 分位，接近但未越过 5% 显著尾部，且主随机组 S4A-R 也达到 0.29535。15 指标方案由此说明“候选池和代理表征更稳”。代理预筛相对随机送审的显著增量在本实验中未建立。

据此，15 指标方案 A 的定位是**稳健升级**：它改善了 `log10_qi` 表示、候选可计算性和 Stage 4 的绝对最好违反量。官方可行解仍为 0。无可行侧数据导致的外推乐观仍在。随后完成的方案 B-small 检验了“保持线上输入仍为边界系数、训练阶段加入 wout 派生低维中间物理标签”的思路，其结果见下一节。

### 5.5 补充证据：wout 中间监督方案 B-small

方案 B-small 的目的，是检验 VMEC++ 平衡解中的中间物理结构能否作为辅助监督，帮助代理模型识别边界到真实平衡状态之间的隐含约束。该方案仍严格遵守线上边界：模型输入只使用 80 维 Fourier 边界系数；wout 不作为线上输入，不参与候选评分时的物理计算；wout 只在训练阶段被压缩成低维标签，用来约束共享表征。具体实现为 `shared encoder -> problem2_head + default_aux_head + wout_head + constraint_head`，其中 problem2 head 预测 6 个 Problem 2 主指标，default_aux head 预测 9 个 default 辅助指标，wout head 预测 24 个 wout 派生标签，constraint head 预测连续 `max_normalized_violation`。

数据构建上，`id_to_file_map` 中可匹配到 63,225 条目标 wout 样本；这些样本分散在 2000 个 parquet part 中，因此无法只下载少数 part 文件完成抽取。最终从已过滤的 wout parquet 中构建出 63,225 行 wout24 标签，24 个标签均有 63,225 个有限值。训练数据覆盖率为：训练集 47,694 行中有 44,232 行带 wout 标签，测试集 10,221 行中有 9,470 行带 wout 标签，优化验证集 3,589 行中有 2,964 行带 wout 标签。由于存在缺失 wout 映射，训练使用 label-wise mask：缺 wout 的样本仍可训练 Problem 2、default_aux 和 constraint 头，不会被整行丢弃。

24 个 wout 派生标签包括五类：低阶 `bmnc/rmnc/zmns/lmns` Fourier-radial profile 的 PCA latent，`iota_full` profile 的 PCA latent 与斜率/曲率统计，`B` 场相关均值与 edge-axis 差异，Mercier/geodesic/jcuru 等稳定性或电流剖面的分位数，以及 `bvco` 标准差。这些标签以低维形式压缩平衡解状态，使网络学习“边界 -> 平衡结构 -> 物理指标”的中间约束。

模型层面结果是正面的。wout24 多头模型在 Problem 2 主任务上没有被辅助任务拖垮，反而多数指标略优于原 15 指标模型：测试集 `log10_qi` MAE 为 0.03817、R² 为 0.97052，优化验证集 `log10_qi` MAE 为 0.04219、R² 为 0.95869；测试集 `max_normalized_violation` MAE 为 0.04181、R² 为 0.98394，优化验证集 MAE 为 0.03202、R² 为 0.97778。wout 辅助头本身也不是不可学习：24 个 wout 标签在测试集上的平均 R² 约 0.857，在优化验证集上的平均 R² 约 0.800。这说明现有 MLP 骨架升级为多头 + masked loss 后，可以适配方案 B-small。

候选审计没有产生额外收益。使用相同的 E0/E1/E2/E3 候选生成流程和每方法 top10 的 VMEC++ 审计预算，wout24 的总体 VMEC++ 成功数为 23/40，低于 15 指标模型的 30/40；最好正向最大违反量为 0.322441，与 15 指标模型持平，最好候选来自 E0 数据库基线。分方法看，E0 保持 10/10 成功，best violation 与 15 指标相同，median violation 从 0.35576 小幅改善到 0.35080；E1 保持 10/10 成功，best 持平但 median violation 从 0.39917 变差到 0.45603；E2 仍为 0/10 成功；E3 从 15 指标模型的 10/10 成功降至 3/10，best violation 从 0.38242 变差到 0.46347，并出现多条慢 VMEC++ 失败。

方案 B-small 的结论分为两层：第一，**模型结构和标签设计是可行的**，wout 中间监督可以被 MLP 学到，并且不会破坏 Problem 2 主指标预测；第二，**当前候选 scoring 没有利用好这些中间监督**，甚至在 E3 中诱导出更多 VMEC++ 不稳定候选。换言之，瓶颈已经从“能不能训练 wout 辅助模型”转移到“如何把 wout 辅助表征变成更保守的候选筛选规则”。下一步若继续方案 B，不应只是把 wout24 模型直接替换原模型，而应显式引入 VMEC-stability/filter head，或重新设计 E3 scoring，使 predicted violation、support penalty、geometry penalty 与 wout 派生不确定性共同约束候选生成。

### 5.6 补充证据：cross-Nfp 预训练方案 C

![四类模型方案综合对比](../../figures/scheme-comparison/fig3_model_scheme_comparison.png)

方案 C 回答的是另一个此前只停留在设计层面的问题：除 68k Nfp=3 主训练池外，剩余约 90k 异 Nfp 样本能否作为有用的表征初始化。该实验没有采用 158k 混合联合训练，因为不同 Nfp 下存在“相同或相近边界参数对应不同物理响应”的潜在标签冲突。实际流程是先剔除 Nfp=3，仅使用 Nfp=1/2/4/5 的 90,494 条 no-error 样本做 15 指标预训练，其中 Nfp 计数分别为 14,607、19,945、27,798 和 28,144；每个 seed 按 81,444/9,050 切分预训练 train/validation。随后载入 backbone 权重，在原 68k Nfp=3 split 上全参数微调，并与随机初始化 baseline 使用相同切分、seed、early stopping 和评价集。

该实验还保留了两个防止归因混乱的细节。Nfp 不与普通 `x_*` 几何特征一起标准化，而是作为 `nfp_over_3` 条件特征单独拼接；普通几何特征在预训练和微调阶段都使用 Nfp=3 train split 的 scaler，使微调输入坐标系与原 baseline 对齐。预训练与微调使用各自阶段的 y scaler，微调时只加载 backbone，不加载物理 head 或 constraint head，因此输出层仍在 Nfp=3 数据上重新收敛。

三种子结果显示，跨 Nfp 预训练带来了稳定的监督指标收益。随机初始化 baseline 的测试集 `log10_qi` MAE 为 0.03927±0.00065；低学习率微调降至 0.03219±0.00062，默认学习率微调降至 0.03201±0.00090。优化验证集上，baseline 的 `log10_qi` MAE 为 0.04326±0.00090；低学习率微调为 0.03446±0.00035，默认学习率微调为 0.03492±0.00083。连续违反量 MAE 也同步下降：测试集从 0.04179±0.00138 降至约 0.0320-0.0324，优化验证集从 0.03053±0.00093 降至 0.02349-0.02480。最终 gate 的规则是“至少两个关键 opt-val 指标跨 seed 平均正向改善”，该规则通过，best run 标记为 `finetune_low_lr_15metric`。

但方案 C 的收益边界同样清楚。`log10_qi` optimistic gap 的绝对值没有稳定下降：低学习率微调在 opt-val 上的 gap 改善均值为 -0.00075，默认学习率为 -0.00206，均不能支持“偏差被校正”的结论。为验证“监督指标改善是否能转化成优化闭环收益”，本项目随后选用 gate 标记的 `finetune_low_lr_15metric_seed0`，把它接入与 report 主线一致的候选生成、诊断、随机对照和固定预算 VMEC++ 审计。该下游流程仍使用 80 维 Fourier 边界系数作为候选输入，预测时按 Nfp=3 train scaler 标准化几何特征，并追加常数 `nfp_over_3=1.0`。

E0-E3 审计结果与此前主线相似：每组 10 个 attempted slots，共 40 个候选，E0/E1/E3 均为 10/10 VMEC++ 成功，E2 为 0/10；所有组官方可行数均为 0。最好正向最大违反量来自 E0/E1 数据库或 relaxed55 附近候选，为 0.32244；E3 最好为 0.35060，未超过数据库基线。Stage 2 中，E2-stage2 仍为 0/10 成功，E3-stage2 为 10/10 成功但最好违反量仍为 0.35060，没有改善 Stage 1 的最好值。Stage 3 trust-region 审计 8 个候选，8/8 成功，最好正向最大违反量为 0.33047，最好 `log10_qi` gap 为 1.0637；候选来源再次塌缩到 E0-old，说明信任域内仍主要是在已有数据库附近重新排序。

Stage 4A 是方案 C 下游最重要的随机对照。该阶段主审计仍为 S4A-1/2/3/4/R 各 10 个 attempted slots，并额外审计 187 个随机辅助候选，用于估计 30 次 S4A-R 随机重复的真值分布；unique 新 VMEC++ 调用为 233。主审计中，S4A-1 仅 1/10 成功、S4A-2 为 0/10，S4A-3 为 10/10、S4A-4 为 9/10、S4A-R 为 6/10；全部官方可行数仍为 0。S4A-4 的最好正向最大违反量为 0.31186，略优于 Stage 1-3 历史最好 0.32244；但随机对照的中位最好违反量为 0.31657，5-95% 区间为 0.31135-0.32463，最小值为 0.31047。S4A-4 只达到随机分布约 0.0667 分位，接近但未越过 5% 显著尾部；S4A-3 和主随机组 S4A-R 的最好值也都在 0.3167 附近。

方案 C 的最终结论分为两层：**模型层面正迁移成立，优化闭环层面不构成突破。** 异 Nfp 数据作为 backbone 初始化，确实改善了 Nfp=3 的 `log10_qi` 与连续违反量预测；optimistic gap 未稳定修正。E0-E3、Stage 2、Stage 3 与 Stage 4A 中官方可行解均为 0。Stage 4A 的小幅最好值改善仍落在随机送审分布内部，尚难可靠归因于代理预筛。因此，cross-Nfp 方案 C 可以作为默认 15 指标模型的新初始化选项。后续仍需要高保真主动学习或可行侧数据回填。

## 第六部分：结论

综合 6 指标主线四阶段实验，以及在其后依次完成的 15 指标方案 A、wout24 方案 B-small、cross-Nfp 预训练方案 C，本项目形成了一条闭合证据链，可概括为如下经实验支持的判断：

> 在没有官方可行侧数据的 QI 仿星器离线设定下，代理模型对 log₁₀(qi) 的预测会在训练边界处饱和；任何施加于固定代理的可行性优先优化，都可能退化为对模型乐观误差的利用，使真实约束 gap 变差；而一旦将搜索限制在代理可信区域内，候选又会退回已有数据库附近，难以产生新解。同时，即便将代理预筛嵌入 ALM-NGOpt 这类更强的优化逻辑中，真实审计结果仍落在随机送审对照分布内部，代理排序本身是否带来可归因增量，在本实验中未得到支持。因此，“固定代理 + 无可行数据”这一组合主要受限于“利用模型误差”“退回数据”和“预筛贡献不可分辨”三种行为模式，离线代理搜索在本实验条件下未能形成通向官方可行域的可靠路径。

本项目 E0-E3 与 Stage 4A 的官方可行候选数均为 0。论文 ALM-NGOpt 在 96 vCPU、34 小时在线物理优化下报告 Problem 2 得分 0.431。本项目采用离线代理生成候选和固定预算 VMEC++ 审计，两组实验的预算与评价流程不同。这里的“零官方可行样本”专指所用的 68k 无错误 Nfp=3 数据子集；论文可行解由独立在线优化流程获得。现有结果指向一个清晰方向：跨越可行线需要覆盖可行侧的新物理信息。

这一负结果具备机制解释、可复现证据和明确边界，也直接回答了“做了哪些改进尝试、为什么有效或无效”：几何修正有效（VMEC++ 成功率 1/10 -> 6/10），15 指标多任务训练还能进一步把部分策略的成功率提升到 10/10，并改善 `log10_qi` 的预测误差；wout24 方案 B-small 证明中间物理监督可被多头 MLP 学到，且测试集 wout 辅助头平均 R² 达到约 0.857，候选 VMEC++ 审计未随 wout 监督自动改善。cross-Nfp 方案 C 说明异 Nfp 数据作为预训练初始化可以稳定改善 Nfp=3 的 `log10_qi` 与连续违反量 MAE；optimistic gap 未稳定修正，完整 downstream 审计官方可行解仍为 0。代理辅助 ALM-NGOpt 能把候选推近违反量下限，15 指标复跑中达到 0.29535；随机对照同步进入相近区间。cross-Nfp Stage 4A 最好值为 0.31186，落在随机对照分布内部。相对随机预筛，可证优势未建立。该判断由距离-偏差曲线、违反量下限、Stage 4A 随机对照、15 指标复跑、wout24 方案 B-small 和 cross-Nfp 预训练及下游审计共同支撑。

与论文的关系也可据此定位：论文附录 A.4 已定性指出代理模型在远离训练分布时容易外推出错，但未量化这一风险，也未讨论它对离线优化的具体后果。本项目的增量在于把这句定性预警转化为可测量的结论：用距离-偏差曲线给出代理可信范围的定量刻画，用违反量下限给出该数据集下的约束边界，并进一步证明在无可行数据时，离线代理优化会被限制在“利用模型误差”与“退回数据”两种行为模式之间；第四阶段还表明：将代理嵌入更接近论文基线的 ALM-NGOpt 搜索逻辑后，代理预筛相对随机送审的可证增量仍未显示。这些结论在论文中均未出现，是本项目在既有工作基础上的具体贡献。

## 第七部分：未来方向与其他技术路线

后续工作优先补充覆盖可行侧或近可行侧的高保真物理信息。Stage 2 已量化高惩罚权重引发的模型误差利用，Stage 4A 已显示更强优化器单独未能提供可归因的预筛增量。方案 A、B-small 和 C 分别改善了辅助物理表示、wout 中间监督和跨 Nfp 初始化，同时保留了可行侧数据缺口。default 基础指标已经是 VMEC++ 高保真量，当前稀缺资源是覆盖官方可行侧的新样本。后续采用按成本递增的分保真策略：

1. **代理加速的 ALM-NGOpt：已完成 Stage 4A 验证**。第四阶段已测试“保留 ALM-NGOpt 搜索逻辑、用代理生成与预筛候选、再用 VMEC++ 固定预算审计”的方案。6 指标主线中，S4A-4 最好值为 0.31318，优于 Stage 1-3 历史最好 0.32214，但仍落在随机对照分布内部。15 指标复跑进一步把 S4A-4 推到 0.29535，不过随机对照也进入相近区间（中位 0.30236，最小 0.28841），因此这一方向的结论更新为：候选生成有价值；作为纯预筛器，可证增量未显示。后续将其定位为候选生成器，最终评价继续使用 VMEC++。
2. **多保真训练与 wout 中间监督：已完成 B-small 验证，后续需改 scoring**。将 default 的 68k 无错误 Nfp=3 数据作为大规模基础预训练标签，15 指标方案 A 已完成增强验证；本项目也已从 `vmecpp_wout_id` 关联的平衡解中提取 24 个低维中间物理标签，验证了多头 MLP + masked loss 的可训练性。下一步将 wout 表征用于 VMEC-stability/filter head 和更保守的候选 scoring。VMEC++ wout 仅提供训练标签，推理输入保持为 Fourier 系数，从而保留代理加速能力。
3. **主动学习闭环**：在上述框架下，将固定预算的 VMEC++ 审计从"一次性"改为多轮闭环：用代理给候选排序，只把高潜力候选送 VMEC++ 真算，再把新结果回填训练集迭代校准模型。在相同总物理预算下，该闭环重新分配审计调用。这些新 VMEC++ 结果正是修正 default 弱标签（如按规则派生的 violation、score）与真实高保真评价之间偏差的关键数据。Stage 4B 本可作为这一方向的起点，但因 Stage 4A 未证明代理预筛显著优于随机送审，门控条件未满足，本项目没有继续启动 4B；这避免了在未被证实的预筛信号上消耗新的物理预算。
4. **迁移与跨数据集**：cross-Nfp 预训练已经完成从三种子监督消融到 E0-E3/Stage 2/Stage 3/Stage 4A 的一轮闭环，说明 Nfp=1/2/4/5 数据作为 backbone 初始化能改善 Nfp=3 监督预测，但不足以单独修正可行性偏差或带来可归因的 VMEC++ 审计收益。更外层的迁移可继续考虑相关数据集（如 QA/QH 的 QUASR），但须注意保真度与问题定义的一致性：finite-beta 或其它 wout 数据与 Problem 2 的 vacuum 标签定义不同，使用时须单独对齐官方评分标签。上述方向也与论文附录 A.4 关于不确定性校准、主动学习和物理信息策略的建议一致。
5. **可微物理（如 DESC）**：使用端到端可微的平衡求解器将物理梯度引入优化，减少对固定代理外推的依赖。
6. **磁面表征研究**：更好的边界表征方式（近轴展开、学习型潜表征、谱带分解等）可能改变可行域在搜索空间中的几何形状，本项目将其主动划在范围之外，作为独立后续课题。

除 Stage 4A、15 指标方案 A、wout24 方案 B-small 和 cross-Nfp 方案 C 已完成验证外，其余方向均需超出本轮物理与计算预算的资源。因此，本报告将其列入后续方向。

## 第八部分：本项目最能体现的能力

抛开“是否找到可行解”这一受数据条件强烈制约的结果，本项目更能体现的是科研判断与工程闭环能力：

1. **抽象建模**：在陌生的聚变物理交叉领域，快速确立“背景-目标-约束”，将问题准确抽象为 80 维、带硬门槛约束的昂贵黑盒优化，并识别出“评估昂贵、约束主导、无可行数据”三个决定性因素。
2. **技术路线选型**：在局部优化、贝叶斯优化、进化算法、强化学习和生成模型之间，基于算力与评估预算做出有依据的取舍，选定可控、可审计且契合 benchmark 数据资产的离线代理路线，并明确划定贡献边界。
3. **小步迭代与诊断**：以四阶段实验逐层排除解释，并通过小步实验定位机制；面对反常结果（可求解率上升而 gap 变差、代理预筛小幅改善但落在随机对照分布内），能定位到机制层面（优化器利用代理误差、代理预测在训练边界饱和、候选池改善与代理排序贡献需分开度量），并形成对“未能求解”原因的机制解释。
4. **对负结果的科学处理**：将“0 个官方可行解”从单纯失败，重构为一个有距离-偏差曲线和违反量下限双重证据支撑、可复现的方法学结论，并诚实标注所有边界（资源受限、单路线、未做表征创新、论文基线未复现）。

这套“抽象复杂问题 -> 选择可落地路线 -> 完成工程闭环 -> 对结果给出机制解释”的能力，是本项目最核心的产出。

### 附：术语速查

- **ConStellaration**：QI-like 仿星器边界数据集与优化 benchmark。
- **Problem 2 / simple-to-build QI**：最大化线圈可制造性指标 L_∇B，同时满足 QI 与几何约束。
- **VMEC++**：理想 MHD 平衡求解器，本项目中作为昂贵的物理仿真程序，用于最终审计。
- **L_∇B**：归一化磁场梯度尺度长度，越大通常意味着线圈越易制造，是本问题优化目标。
- **log₁₀(qi)**：QI 残差，本问题中的主要绑定约束。
- **relaxed55**：本地按放宽标准筛出的 55 个近可行种子，仅作生成先验，非官方可行集。
- **6 指标主线模型**：本项目最初的离线代理模型，同时预测 Problem 2 的 6 个主物理指标，并完成 E0-E3、Stage 2、Stage 3 与 Stage 4A 四阶段诊断。
- **15 指标方案 A**：训练阶段同时预测 default 数据中的 15 个物理指标，线上输入仍为 80 维边界系数，线上评分仍只读取 Problem 2 的 6 个主指标。
- **wout**：VMEC++ 平衡求解输出。本项目不把 wout 用作线上输入；已完成的方案 B-small 只从 wout 中提取低维中间监督标签。
- **wout24 方案 B-small**：训练阶段同时预测 Problem 2 主指标、default 辅助指标和 24 个 wout 派生中间标签；线上输入仍为 80 维边界系数，线上评分仍只读取 Problem 2 主指标和连续违反量。
- **cross-Nfp 方案 C**：先用剔除 Nfp=3 后的 90,494 条 Nfp=1/2/4/5 样本训练 15 指标 backbone，再在 68k Nfp=3 协议上微调；Nfp 作为单独条件输入，几何 scaler 仍来自 Nfp=3 train split；已完成 downstream 审计但未产生官方可行解。
- **正向最大约束违反量（positive max violation）**：所有归一化约束违反量正部分的最大值，越低越接近可行。
- **代理可信范围**：代理模型预测仍较可靠的区域；在本实验中，该范围随候选距训练数据的距离增大而失效。
- **PCA**：主成分分析，用真实样本的线性主方向把 80 维傅里叶系数压缩到低维潜空间，降低独立采样造成非法几何的概率。
- **GMM**：高斯混合模型，用多个高斯分量拟合 relaxed55 附近的局部分布，用于生成近可行种子周围的候选。
- **CMA-ES**：协方差矩阵自适应进化策略，通过更新采样分布的均值、步长和协方差来搜索连续黑盒目标。
- **NGOpt**：Nevergrad 的组合型黑盒优化器，根据搜索空间和预算自动选择内部策略，本项目用它作为稳健的工程优化器。
- **ALM-NGOpt**：增广拉格朗日约束处理与 NGOpt 搜索的组合；本项目第四阶段只使用代理评价版，不等价于论文中的在线 VMEC++ 物理优化。
- **信任域**：由不确定性、训练集距离、relaxed55 距离和谱几何规则共同定义的候选可信区域。
- **surrogate arbitrage**：优化器利用代理模型外推误差获得虚高代理分数的现象；对应候选的真实物理指标没有同步改善。
