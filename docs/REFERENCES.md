## Attribution practice

Cite the benchmark paper for the dataset, problem definitions, official
baselines, scoring logic, and evaluation framework. Cite VMEC++ when discussing
the equilibrium solver or high-fidelity audit. Cite this repository only for the
offline surrogate methodology and its implementation.
